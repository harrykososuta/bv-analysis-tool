# BV計 解析ツール (DCS-100NX)

透析用BV計のCSVを取り込み、dBV(循環血液量変化率)と血圧低下の関係を可視化・蓄積するStreamlitアプリ。

## ダウンロードして使う（Windows）

このツールは、各自のPCで起動してブラウザーから操作します。取り込んだCSV・患者情報・解析結果は、そのPC内に保存されます。通常の操作でGitHubへ患者データを送信する機能はありません。

### 1. ダウンロード

1. 共有されたGitHubリポジトリを開きます。**privateリポジトリのため、招待されたGitHubアカウントでログインし、招待を承認してください。**
2. 「Code」→「Download ZIP」を選びます。
3. ZIPを右クリックして「すべて展開」します。ZIP内から直接起動せず、展開後のフォルダを使ってください。

### 2. 初回セットアップ

- 対象: Windows、64ビット版Python **3.11〜3.13**。
- Pythonが入っていない場合は、[Python公式サイト](https://www.python.org/downloads/windows/)から対応するバージョンをインストールします。インストーラーに「Add python.exe to PATH」がある場合はチェックを入れてください。
- 展開したフォルダの **`setup.bat`をダブルクリック**します。ツール専用の環境（`.venv`）を作り、必要なライブラリをインストールします。初回はインターネット接続が必要です。
- 「Setup complete」と表示されたら完了です。エラーが出た場合は、画面の内容を確認し、解決後にもう一度`setup.bat`を実行します。

### 3. 起動・終了

1. **`run.bat`をダブルクリック**します。2回目以降はこれだけで起動できます。
2. ブラウザーが開かない場合は、起動したまま <http://127.0.0.1:8501> を開きます。
3. 「① 取り込み」でDCS-100NX形式のCSVを選び、取り込んで解析します。
4. 終了する際は、起動時に開いた黒い画面で`Ctrl+C`を押します。ブラウザーを閉じるだけではツールは終了しません。

### 保存場所・更新

- 既定の保存先は **`%USERPROFILE%\BV_Tool_Data`** です。Windowsのエクスプローラーのアドレス欄に貼り付けると開けます。DB、患者別CSV、設定はダウンロードしたツールのフォルダとは別に保存します。`BV_DATA_DIR`を設定した場合はその保存先を使います。
- 「⑧ 設定」で保存場所を確認し、バックアップ先を設定してください。バックアップ先の初期値は未設定です。
- 更新時は、ツールを終了してバックアップを作成し、最新版ZIPを**別のフォルダへ展開**します。新しいフォルダで`setup.bat`、続いて`run.bat`を実行してください。同じWindowsユーザーで保存先を変えていなければ、既存データを引き続き使えます。
- `.venv`はコピーせず、展開したフォルダごとにセットアップしてください。フォルダを移動した場合も、移動先の`.venv`だけを削除して`setup.bat`を再実行します。
- エラーを報告する際は、患者氏名・CSV・DBが写り込まないようにしてください。

### コマンドから起動する場合

セットアップ済みのフォルダで次を実行します。起動ファイルもこの専用環境を使います。

```bat
.venv\Scripts\python.exe -m streamlit run app.py
```

## リポジトリの管理と共有

- リポジトリは**private**で管理し、GitHubの「Settings」→「Collaborators」から利用者を招待します。
- GitHubへの掲載対象はソースコードと説明書です。**privateであっても患者CSV・DB・出力ファイル・バックアップ・認証情報をコミットしないでください。**
- `.gitignore`でCSV、Excel、DB、患者フォルダ、バックアップ、`.venv`、ローカルの認証設定などを除外しています。画像やその他のファイルにも患者情報が含まれないか、追加する前に確認してください。
- GitHubのIssuesを使う場合も、患者情報を添付しないでください。

## 構成

| ファイル | 役割 |
|---|---|
| `app.py` | 画面(下記「画面」参照) |
| `bv_parser.py` | CSV読み込み、単位変換(×10・×100)、欠測(-9999)処理、氏名除去 |
| `analysis.py` | 血圧測定点の検出、血圧低下判定、BV指標、段階別集計、平均曲線 |
| `stats_models.py` | 患者内比較(Mantel-Haenszel)・GEEロジスティック回帰・除水量の目安(概算)・除水停止の関連 |
| `ufc.py` | BV-UFCの設定・目標ΔBVカーブ・ΔBV/除水量の予測シミュレーション・ステップ別の実績集計 |
| `bv_settings.py` | 設定(settings.json)と、バックアップ(DBの整合コピー・世代管理・元CSVの複製) |
| `db.py` | SQLite(`bv_research.db`)と患者別フォルダ(`patients/<患者ID>/`) |

## データの扱い

- CSV 1行目の「ID」は**装置(コンソール)の番号**で、同じ装置を複数の患者が使います。患者は**氏名**で区別し、患者IDは氏名から作った記号（例 `P3F2A91C0`、氏名そのものは含まない）です。装置の番号は症例ごとに「装置」として記録します。氏名が無いCSVは `不明_<装置>` として登録します。
- 同じ人が別の表記の氏名で登録された場合は、データ管理 → 患者 →「患者の統合」でまとめられます（似た氏名の組を表示します）。
- 旧版（装置の番号を患者IDにしていた）のDBは、初回起動時に氏名で患者を分け直し、元CSVを患者ごとのフォルダへ移します（実行前に `bv_research_before_patient_split.db` を作成）。
- 氏名は**このPC内のDBにのみ**保存します（サイドバー「氏名を表示」OFFで画面上は伏せられます）。
- 元CSVは `<保存先>/patients/<患者ID>/` に複製保存します(氏名除去は取り込み画面で選択)。
- 重複は取り込み時に自動で振り分けます。
  - 同一内容のCSV(SHA-256)はスキップ
  - 同じ患者で測定時間が重なるCSV(途中出力・再出力など)は同一症例とみなし、行数の多いデータを1つだけ採用。登録済みより長ければ置換し、入力済みの臨床記録・体重は引き継ぐ
  - 同じ日でも時間が重ならなければ別症例として取り込む(備考に「同日に別症例あり」と表示)
- 保存先の既定は `C:\Users\<ユーザー名>\BV_Tool_Data`(OneDrive等のクラウド同期の外)。変更は環境変数 `BV_DATA_DIR`。
- アプリは `127.0.0.1` のみで待ち受けます(`.streamlit/config.toml`)。他のPCからは接続できません。
- 出力(CSV/Excel)に氏名を含めるかは、データ管理画面で選べます(既定は含めない)。
- 保存先には患者データが入るため、Git等にコミットしないでください。

## 解析の前提

- 血圧は装置が測定値を保持して出力するため、sbp/dbp/脈拍が前行から**変化した行を測定点**とみなします
  (同一値が連続した測定は検出できません)。
- 血圧低下の判定基準はサイドバーで選択(標準: 最初の測定SBPから20mmHg以上低下、またはSBP<90mmHg ほか複数のプリセット/カスタム)。
- 「データ管理」で臨床的な血圧低下の有無を入力した症例は、自動判定より優先して集計します。
- `event` 列は取扱説明書(表12-1)に基づき名称を表示します。20秒以内の複数発生は2桁ずつ連結される(例: 203 = 除水停止+除水再開)ため分解しています。

## 画面

1. 取り込み — CSVの複数選択/フォルダ一括。治療モード・時間群をプレビュー
2. 症例解析 — ΔBV・血圧・除水の3段グラフ、イベント(取扱説明書の表12-1に基づく名称)、臨床記録
3. 患者別 — 症例の重ね描き / 全症例の統合グラフ。治療時間群・治療モードで絞り込み
4. 症例間比較・統計 — 群間比較、散布図、患者ごとの平均曲線、治療時間群・モード別、判定基準の比較
5. 血圧低下とΔBV — 4時間群vs5時間群(患者内)、調整解析(GEE)、除水量の目安(概算)、低下直前のΔBV推移、予測性(ROC/AUC)、ΔBV水準ごとの低下率、低下後の除水停止
6. BV-UFC — 装置と同じ項目で設定を試し、患者ごとにΔBV・除水量・血圧低下リスクを予測。指数ごとの目安(各時点の予測ΔBV・リスクと、その患者で血圧低下なく終えた症例の経過の形)。BV-UFC使用症例の実績(ステップ別・指数の到達度)。設定の保存
7. データ管理 — 臨床記録の入力(除水量はCSV値を表示)、患者情報、エクスポート、削除
8. 設定 — 保存場所の表示、バックアップ(自動/手動)

## 用語・分類

- 治療時間群: 5時間群(270分以上) / 4時間群(210〜270分) / 短時間(210分未満)
- 治療モード: CSVのY列(treat-mode)。HD / O-HDF(pre) / I-HDF など。治療中に変化した場合は最頻モードで分類
- 血圧の -1 は「未測定」として欠測扱い
- リファレンスエリア: 装置が前体重と除水量から算出する統計的な基準領域
- BV-UFCステップ: CSVの `BV-UFC step no`。1=開始(約5分)、3〜6=治療時間をほぼ4等分した区間(各区間の終わりに 指数1・2・3・終了時ΔBV へ達するよう制御)、7=最終、0=停止。取り込み実績からの推定
- 指数: 終了時ΔBVに対する%(開始時ΔBVから終了時ΔBVまでの何%か)
- CSV 1行目に記録されるBV-UFC関連の設定値: 治療時間・目標除水量・開始/定倍除水の時間と倍率・終了前の時間。指数・終了時ΔBV・UFC上限/下限は記録されない

## 解析上の注意

- 患者内比較・調整解析・除水量の目安は、観察データの探索的な解析です。因果や臨床上の指示を示すものではありません。
- 除水量の目安は、過去に実施された除水量と血圧低下の関係からの統計的な概算です（体重・血圧薬・体液量は考慮していません）。
- BV-UFCの予測は簡易モデルです: ΔBVの変化 = −100/循環血液量 ×(除水速度 − PRR)。循環血液量は装置が記録したPRRから逆算、PRRは過去症例の除水量の収支(水準)と装置のPRR(ΔBV・時間との関係)から患者ごとに推定。UFC中は2分ごとにΔBVの変化率を目標カーブに合わせるよう除水速度を更新(装置の制御そのものではない)。直近症例での検証では、除水量の誤差は中央値で約±0.4 L(患者により異なる・画面に表示)。
